# 🚀 Vibe-Check Content Engine

An advanced, high-retention social media content generator powered by **Pollinations.ai**. This application transforms simple topics into structured viral scripts paired with cinematic AI-generated visuals.

## 🛠️ Tech Stack
- **Framework:** Next.js 15 (App Router)
- **AI Backend:** Pollinations.ai API
- **Models:** `nova-fast` (Text), `flux` (Images)
- **Styling:** Tailwind CSS + Lucide Icons
- **Deployment:** Vercel

## ✨ Features
- **Structured Output:** Uses `jsonMode` for consistent API parsing.
- **Optimized Prompts:** Custom system logic to turn raw data into "Viral Hooks."
- **Mobile First:** Fully responsive UI designed for content creators on the go.
- **High Performance:** Utilizes the `nova-fast` model for near-instant responses.

## 🚀 Getting Started
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
